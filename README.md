## Sobre o Projeto
Sistema executado via terminal para gerenciamento de clientes, pets e serviços de um PetShop. A arquitetura aplica os pilares da Orientação a Objetos:
* **Encapsulamento:** Atributos privados (`__`) protegidos por *getters* e *setters* com validação de regras de negócio.
* **Herança e Polimorfismo:** Hierarquia de classes utilizando `super().__init__()` e sobrescrita de métodos percorridos em listas heterogêneas.
* **Tratamento de Exceções:** Blindagem de menus e entradas com `while True` e `try/except` para evitar falhas durante a execução.
